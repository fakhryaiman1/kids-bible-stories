# قصص الكتاب المقدس للأطفال

A premium, child-friendly Bible stories platform built with React, TypeScript, Tailwind CSS, Framer Motion, and Supabase.

## Features
- Beautiful story library experience for kids
- Admin dashboard for content management
- Supabase-backed data model with reusable UI
- Production-ready front-end structure

## Setup
1. Install dependencies: npm install
2. Create a Supabase project and add the environment variables:
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY
3. Run the app: npm run dev
